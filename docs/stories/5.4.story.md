### Stack Architecture

[Source: architecture/3-stack-technologique.md]

**Production Stack:**

```
[Flutter Mobile App]
    ↓ HTTPS/API
[Nginx] → [PHP-FPM 8.2] → [Laravel 11]
                              ↓
                          [MySQL 8.0]
                              ↓
                    [OVH Object Storage]
```

**Key Components:**
- **Nginx:** Reverse proxy, SSL termination, static files

### Nginx Configuration for Laravel

**Complete Nginx Site Configuration:**

```nginx
server {
    listen 80;
    server_name api.travelconnect.app;
    return 301 https://$server_name$request_uri;
}

server {
    listen 443 ssl http2;
    server_name api.travelconnect.app;

    root /var/www/travelconnect-api/public;
    index index.php;

    # SSL Configuration (managed by Certbot)
    ssl_certificate /etc/letsencrypt/live/api.travelconnect.app/fullchain.pem;
    ssl_certificate_key /etc/letsencrypt/live/api.travelconnect.app/privkey.pem;
    ssl_protocols TLSv1.2 TLSv1.3;
    ssl_ciphers HIGH:!aNULL:!MD5;

    # Security Headers
    add_header X-Frame-Options "SAMEORIGIN" always;
    add_header X-Content-Type-Options "nosniff" always;
    add_header X-XSS-Protection "1; mode=block" always;
    add_header Strict-Transport-Security "max-age=31536000; includeSubDomains" always;

    # Logging
    access_log /var/log/nginx/travelconnect-access.log;
    error_log /var/log/nginx/travelconnect-error.log;

    # Client upload size
    client_max_body_size 10M;

    # Gzip compression
    gzip on;
    gzip_vary on;
    gzip_proxied any;
    gzip_comp_level 6;
    gzip_types text/plain text/css text/xml text/javascript application/json application/javascript application/xml+rss application/rss+xml font/truetype font/opentype application/vnd.ms-fontobject image/svg+xml;

    # Laravel routes
    location / {
        try_files $uri $uri/ /index.php?$query_string;
    }

    # PHP-FPM
    location ~ \.php$ {
        fastcgi_pass unix:/var/run/php/php8.2-fpm.sock;
        fastcgi_index index.php;
        fastcgi_param SCRIPT_FILENAME $realpath_root$fastcgi_script_name;
        include fastcgi_params;

        # Timeouts
        fastcgi_read_timeout 300;
        fastcgi_send_timeout 300;
    }

    # Deny access to hidden files
    location ~ /\.(?!well-known).* {
        deny all;
    }

    # Rate limiting for API
    location /api/ {
        limit_req zone=api burst=10 nodelay;
        try_files $uri $uri/ /index.php?$query_string;
    }
}

# Rate limiting zone definition (add to http block in nginx.conf)
# limit_req_zone $binary_remote_addr zone=api:10m rate=60r/m;
```

   ```bash

   sudo systemctl start fail2ban
   ```

3. **SSH Hardening:**
   - Disable root login

   - Remove test database

   - Limit user privileges
   - Disable remote root access

   - Set `APP_DEBUG=false`
   - Configure rate limiting
   - Enable CSRF protection
   - Use HTTPS only
   - Implement proper error handling

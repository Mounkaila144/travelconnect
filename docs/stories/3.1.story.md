## Acceptance Criteria

1. Le bouton "Répondre" sur le détail question ouvre un champ de saisie
2. La réponse accepte du texte (max 1000 caractères)
3. Un compteur de caractères indique la limite
4. Le bouton "Envoyer" publie la réponse
5. La réponse apparaît immédiatement dans la liste
6. L'auteur de la question reçoit une notification (voir Epic 4)
7. L'endpoint POST `/api/questions/{id}/answers` crée une réponse
8. Un utilisateur peut poster plusieurs réponses à la même question

### Answer Model Specification

[Source: architecture/4-modèles-de-données.md#4.3]

**Answer Model Attributes:**
- `id`: bigint - Unique identifier
- `question_id`: bigint - Associated question (FK)
- `user_id`: bigint - Answer author (FK)
- `content`: text - Answer content (max 1000 characters)
- `average_rating`: decimal(2,1)|null - Average rating (calculated from ratings)
- `ratings_count`: int - Number of ratings received
- `is_deleted`: boolean - Soft delete flag
- `created_at`, `updated_at`: timestamp

**Relationships:**
- Belongs to Question
- Belongs to User
- Has many Ratings
- Has many Reports

**Database Indexes:**
- Index on `question_id` for efficient answer queries
- Composite index on `(question_id, created_at)` for sorted lists

### API Endpoint Specification

[Source: architecture/5-spécification-api-rest.md#5.3.5]

**Endpoint:** `POST /api/questions/{id}/answers`

**Authentication:** Required (Bearer token)

**Request Body:**
```json
{
  "content": "Je recommande Ichiran, c'est délicieux et ouvert tard !"
}
```

**Validation Rules:**
- `content`: required, string, max:1000

**Success Response (201 Created):**
```json
{
  "data": {
    "id": 1,
    "content": "Je recommande Ichiran, c'est délicieux et ouvert tard !",
    "average_rating": null,
    "ratings_count": 0,
    "created_at": "2026-01-31T09:00:00Z",
    "user": {
      "id": 2,
      "name": "Tanaka Yuki",
      "avatar_url": "https://storage.../avatar.jpg",
      "user_type": "local_supporter",
      "trust_score": 4.5
    },
    "user_rating": null
  }
}
```

**Error Responses:**
- `401 Unauthorized` - User not authenticated
- `403 Forbidden` - User is banned
- `404 Not Found` - Question does not exist
- `422 Validation Error` - Invalid content (empty or too long)

### Backend Implementation Details

[Source: architecture/11-architecture-backend-laravel.md#11.1]

**File Location:** `app/Services/AnswerService.php`

**Key Methods:**

```php
<?php

namespace App\Services;

use App\Events\AnswerCreated;
use App\Models\Answer;
use App\Models\Question;
use App\Models\User;
use Illuminate\Support\Facades\DB;

class AnswerService
{
    /**
     * Create a new answer
     */
    public function createAnswer(Question $question, User $user, array $data): Answer
    {
        // Verify question is not deleted
        if ($question->is_deleted) {
            throw new \InvalidArgumentException('Cette question n\'existe plus');
        }

        DB::beginTransaction();
        try {
            // Create answer
            $answer = Answer::create([
                'question_id' => $question->id,
                'user_id' => $user->id,
                'content' => $data['content'],
            ]);

            // Increment answers count on question
            $question->increment('answers_count');

            // Mark question as having unread answers (if answerer is not question author)
            if ($question->user_id !== $user->id) {
                $question->update(['has_unread_answers' => true]);
            }

            // Load user relationship
            $answer->load('user');

            // Fire event for notification
            event(new AnswerCreated($answer, $question));

            DB::commit();

            return $answer;
        } catch (\Exception $e) {
            DB::rollBack();
            throw $e;
        }
    }

    /**
     * Get answers for a question with user ratings
     */
    public function getAnswersForQuestion(int $questionId, User $currentUser, int $page = 1): array
    {
        $perPage = 20;

        $answers = Answer::where('question_id', $questionId)
            ->where('is_deleted', false)
            ->with(['user'])
            ->withCount('ratings')
            ->orderByDesc('average_rating')
            ->orderByDesc('created_at')
            ->paginate($perPage, ['*'], 'page', $page);

        // Attach current user's rating to each answer
        foreach ($answers as $answer) {
            $userRating = $answer->ratings()
                ->where('user_id', $currentUser->id)
                ->first();

            $answer->user_rating = $userRating?->score;
        }

        return [
            'answers' => $answers,
            'pagination' => [
                'current_page' => $answers->currentPage(),
                'last_page' => $answers->lastPage(),
                'per_page' => $answers->perPage(),
                'total' => $answers->total(),
            ],
        ];
    }
}
```

**Controller Implementation:**

```php
<?php

namespace App\Http\Controllers\Api;

use App\Http\Controllers\Controller;
use App\Http\Requests\CreateAnswerRequest;
use App\Http\Resources\AnswerResource;
use App\Models\Question;
use App\Services\AnswerService;
use Illuminate\Http\JsonResponse;

class AnswerController extends Controller
{
    public function __construct(
        private readonly AnswerService $answerService
    ) {}

    /**
     * Create a new answer
     */
    public function store(CreateAnswerRequest $request, int $questionId): JsonResponse
    {
        $question = Question::findOrFail($questionId);

        $answer = $this->answerService->createAnswer(
            question: $question,
            user: $request->user(),
            data: $request->validated()
        );

        return response()->json([
            'data' => new AnswerResource($answer)
        ], 201);
    }
}
```

```php
namespace App\Listeners;

use App\Events\AnswerCreated;

class SendNewAnswerNotification
{
    public function __construct(
        private readonly NotificationService $notificationService
    ) {}

    public function handle(AnswerCreated $event): void
    {
        // Only notify if answerer is not the question author
        if ($event->answer->user_id === $event->question->user_id) {

            answer: $event->answer,

    }
}
```

### Optimistic UI Update Pattern

**Pattern:** Show answer immediately, update when server confirms

```dart
Future<void> _submitAnswer(String content) async {
  // Create temporary answer
  final tempAnswer = Answer(
    id: -1, // Temporary ID
    content: content,
    user: currentUser,
    createdAt: DateTime.now(),
    isPending: true,
  );

  // Add to list immediately
  setState(() {
    answers.insert(0, tempAnswer);
  });

  // Submit to server
  final result = await createAnswerUseCase(CreateAnswerParams(
    questionId: widget.questionId,
    content: content,
  ));

  result.fold(
    (failure) {
      // Remove temporary answer on error
      setState(() {
        answers.removeWhere((a) => a.id == -1);
      });
      showError(failure.message);
    },
    (serverAnswer) {
      // Replace temporary with server answer
      setState(() {
        final index = answers.indexWhere((a) => a.id == -1);
        if (index != -1) {
          answers[index] = serverAnswer;
        }
      });
    },
  );
}
```

### Security Considerations

[Source: architecture/15-sécurité-et-performance.md]

**Critical Security Rules:**
1. **ALWAYS** validate content length server-side (max 1000 chars)
2. **ALWAYS** sanitize answer content before display (prevent XSS)
3. **ALWAYS** verify user is authenticated via Sanctum middleware
4. **ALWAYS** check user is not banned before allowing answer creation
5. **NEVER** trust client-side validation only
6. **IMPLEMENT** rate limiting: Max 10 answers per user per hour

**Rate Limiting Configuration:** `config/api.php`

```php
'throttle:answers' => [
    'limit' => 10,
    'decay_minutes' => 60,
],
```

**Apply in routes:**
```php
Route::post('/questions/{question}/answers', [AnswerController::class, 'store'])
    ->middleware(['auth:sanctum', 'not.banned', 'throttle:answers']);
```

### Question Model - has_unread_answers Field

[Source: architecture/4-modèles-de-données.md#4.2]

**Field Purpose:**
- Boolean flag indicating if question has new answers since last viewed
- Initially false when question is created
- Set to true when new answer is posted (Epic 3)
- Set to false when question author views question detail
- Used to show unread indicator in "Mes Questions" list

**Backend Logic:**
```php
// When new answer is created (Epic 3)
$question->update(['has_unread_answers' => true]);

// When question author views detail
if ($question->user_id === $currentUser->id && $question->has_unread_answers) {
    $question->update(['has_unread_answers' => false]);
}
```

**Frontend Usage:**
- Display visual indicator (red badge) when true
- Clear indicator when user views question
- Helps users track which questions have activity

### Pagination Strategy

**Infinite Scroll:**
- Automatically load more as user scrolls
- Better UX than manual "Load More" button
- Detect scroll position at 90% of max scroll
- Load next page when threshold reached
- Show loading indicator at bottom during load

**Implementation:**
```dart
class MyQuestionsPage extends StatefulWidget {
  @override
  State<MyQuestionsPage> createState() => _MyQuestionsPageState();
}

class _MyQuestionsPageState extends State<MyQuestionsPage> {
  final _scrollController = ScrollController();

  @override
  void initState() {
    super.initState();
    _scrollController.addListener(_onScroll);
    context.read<MyQuestionsBloc>().add(LoadMyQuestions());
  }

  void _onScroll() {
    if (_scrollController.position.pixels >=
        _scrollController.position.maxScrollExtent * 0.9) {
      final state = context.read<MyQuestionsBloc>().state;
      if (state is MyQuestionsLoaded && state.hasMore && !state.isLoadingMore) {
        context.read<MyQuestionsBloc>().add(LoadMoreMyQuestions());
      }
    }
  }

  @override
  void dispose() {
    _scrollController.dispose();
    super.dispose();
  }
}
```

**State Management:**
```dart
class MyQuestionsLoaded extends MyQuestionsState {

  final bool isLoadingMore;

}
```

### Sorting and Ordering

**Sort Order:** Created At DESC (newest first)

**Reasoning:**
- Users want to see their most recent questions first
- Recent questions more likely to have activity
- Matches common pattern in messaging/social apps

**Alternative Sorting (Future Enhancement):**
- Sort by activity (questions with recent answers first)
- Sort by answer count (most answered first)
- Filter by status (unanswered only)

### Performance Optimization

**List Performance:**
- Use ListView.builder (lazy loading)
- Limit initial load to 20 items
- Cache images with cached_network_image
- Avoid rebuilding entire list on updates

**Network Optimization:**
- Cache API responses (5 min TTL)
- Debounce pull-to-refresh (prevent spam)
- Batch updates (don't reload after every detail view)

**Memory Management:**
- Dispose scroll controller
- Clear bloc state when leaving page
- Limit stored questions to current page + next page

### Error Handling

**Error Scenarios:**

1. **Network Error:**
   - Show error message with retry button
   - Keep cached data if available
   - "Erreur de connexion. Vérifiez votre connexion internet."

2. **Empty Results (No Questions):**
   - Show empty state (not error)
   - Encourage user to create first question

3. **Unauthorized (401):**
   - Session expired
   - Redirect to login

**Error Messages:**

```php
<?php

namespace Tests\Feature\Questions;

use App\Models\Question;

use Illuminate\Foundation\Testing\RefreshDatabase;
use Tests\TestCase;

class GetUserQuestionsTest extends TestCase
{
    use RefreshDatabase;

    public function test_returns_only_authenticated_users_questions(): void
    {
        $user = User::factory()->create();
        $otherUser = User::factory()->create();

        $userQuestion = Question::factory()->create([
            'user_id' => $user->id,

        ]);

            'user_id' => $otherUser->id,
            'title' => 'Other Question',
        ]);

        $response = $this->actingAs($user)->getJson('/api/user/questions');

        $response->assertOk()
            ->assertJsonCount(1, 'data')
            ->assertJsonPath('data.0.id', $userQuestion->id)
            ->assertJsonPath('data.0.title', 'My Question');
    }

    public function test_questions_are_sorted_by_date_desc(): void
    {
        $user = User::factory()->create();

        $oldQuestion = Question::factory()->create([
            'user_id' => $user->id,
            'created_at' => now()->subDays(2),
        ]);

        $newQuestion = Question::factory()->create([
            'user_id' => $user->id,
            'created_at' => now(),
        ]);

        $response = $this->actingAs($user)->getJson('/api/user/questions');

        $response->assertOk()
            ->assertJsonPath('data.0.id', $newQuestion->id)
            ->assertJsonPath('data.1.id', $oldQuestion->id);
    }

    public function test_pagination_works_correctly(): void
    {
        $user = User::factory()->create();

        Question::factory()->count(25)->create(['user_id' => $user->id]);

        $response = $this->actingAs($user)->getJson('/api/user/questions?page=1');

        $response->assertOk()
            ->assertJsonCount(20, 'data')
            ->assertJsonPath('meta.current_page', 1)
            ->assertJsonPath('meta.last_page', 2)
            ->assertJsonPath('meta.total', 25);
```

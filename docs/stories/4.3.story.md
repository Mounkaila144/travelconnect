## Story

**En tant que** Local Supporter,
**Je veux** être notifié des nouvelles questions dans ma zone,
**Afin de** pouvoir aider rapidement les voyageurs.

---

## Acceptance Criteria

1. Les Local Supporters peuvent définir leur zone d'intérêt (ville/rayon)
2. Une notification est envoyée quand une question est postée dans cette zone
3. La notification contient : "Nouvelle question près de [lieu]" + titre
4. Maximum 5 notifications par jour pour éviter le spam
5. L'utilisateur peut ajuster le rayon ou désactiver dans les paramètres
6. L'endpoint PUT `/api/user/notification-zone` configure la zone

### Spatial Queries for Notification Zones

[Source: architecture/9-schéma-de-base-de-données.md]

**Users Table - Notification Zone Fields:**
- `notification_zone_lat` - DECIMAL(10,8) NULL - Center latitude
- `notification_zone_lng` - DECIMAL(11,8) NULL - Center longitude
- `notification_zone_radius` - INT UNSIGNED NULL - Radius in kilometers

**Spatial Query Pattern:**
```sql
SELECT u.*
FROM users u
WHERE u.user_type = 'local_supporter'
  AND u.fcm_token IS NOT NULL
  AND u.notification_zone_lat IS NOT NULL
  AND u.notification_zone_lng IS NOT NULL
  AND ST_Distance_Sphere(
      ST_SRID(POINT(u.notification_zone_lng, u.notification_zone_lat), 4326),
      ST_SRID(POINT(?, ?), 4326)
  ) <= u.notification_zone_radius * 1000;
```

**Index for Performance:**
```sql
CREATE INDEX idx_notification_zone ON users(notification_zone_lat, notification_zone_lng);
CREATE INDEX idx_user_type_fcm ON users(user_type, fcm_token);
```

### API Endpoint Specification

[Source: architecture/5-spécification-api-rest.md#5.3.3]

**Endpoint:** `PUT /api/user/notification-zone`

**Request Body:**
```json
{
  "latitude": 35.6762,
  "longitude": 139.6503,
  "radius_km": 10
}
```

**Validation Rules:**
- `latitude`: required, numeric, between:-90,90
- `longitude`: required, numeric, between:-180,180
- `radius_km`: required, integer, min:1, max:50

**Success Response (204 No Content):**
No body returned.

**Error Responses:**
- `401 Unauthorized` - User not authenticated
- `422 Validation Error` - Invalid coordinates or radius

**Error Format:**
```json
{
  "error": {
    "code": "VALIDATION_ERROR",
    "message": "Les données fournies sont invalides",
    "details": {
      "latitude": ["La latitude doit être entre -90 et 90"],
      "radius_km": ["Le rayon doit être entre 1 et 50 km"]
    },
    "timestamp": "2026-01-31T10:00:00Z"
  }
}
```

### NotifyNearbyLocalSupporters Listener Implementation

[Source: architecture/11-architecture-backend-laravel.md#11.1]

**File Location:** `app/Listeners/NotifyNearbyLocalSupporters.php`

**Complete Implementation:**

```php
<?php

namespace App\Listeners;

use App\Events\QuestionCreated;
use App\Repositories\Contracts\UserRepositoryInterface;
use App\Services\FCMService;
use App\Services\NotificationService;
use Illuminate\Contracts\Queue\ShouldQueue;
use Illuminate\Queue\InteractsWithQueue;
use Illuminate\Support\Facades\Log;

class NotifyNearbyLocalSupporters implements ShouldQueue
{
    use InteractsWithQueue;

    private const MAX_DAILY_NOTIFICATIONS = 5;

    public function __construct(
        private readonly UserRepositoryInterface $userRepository,
        private readonly FCMService $fcmService,
        private readonly NotificationService $notificationService
    ) {}

    public function handle(QuestionCreated $event): void
    {
        $question = $event->question;

        // Find Local Supporters with notification zones covering this question
        $localSupporters = $this->userRepository->findNearbyLocalSupporters(
            latitude: $question->latitude,
            longitude: $question->longitude
        );

        Log::info('Found nearby Local Supporters', [
            'question_id' => $question->id,
            'count' => $localSupporters->count(),
        ]);

        foreach ($localSupporters as $supporter) {
            // Check notification preferences
            $settings = $supporter->notification_settings ?? [];
            if (isset($settings['nearby_questions']) && $settings['nearby_questions'] === false) {
                continue;
            }

            // Check daily notification limit
            $dailyCount = $this->notificationService->getDailyNotificationCount(
                userId: $supporter->id,
                type: 'nearby_question'
            );

            if ($dailyCount >= self::MAX_DAILY_NOTIFICATIONS) {
                Log::info('User hit daily notification limit', [
                    'user_id' => $supporter->id,
                    'count' => $dailyCount,
                ]);
                continue;
            }

            // Build notification payload
            $locationName = $question->location_name ?? $question->city ?? 'votre zone';
            $title = sprintf('Nouvelle question près de %s', $locationName);
            $body = $this->truncate($question->title, 100);

            $data = [
                'type' => 'nearby_question',
                'question_id' => (string) $question->id,
            ];

            // Send push notification
            $sent = $this->fcmService->sendNotification(
                fcmToken: $supporter->fcm_token,
                notification: ['title' => $title, 'body' => $body],
                data: $data
            );

            if ($sent) {
                // Create notification record
                $this->notificationService->createNotification(
                    userId: $supporter->id,
                    type: 'nearby_question',
                    title: $title,
                    body: $body,
                    data: $data
                );

                Log::info('Nearby question notification sent', [
                    'question_id' => $question->id,
                    'supporter_id' => $supporter->id,
                    'daily_count' => $dailyCount + 1,
                ]);
            }
        }
    }

    private function truncate(string $text, int $length): string
    {
        return strlen($text) > $length
            ? substr($text, 0, $length) . '...'
            : $text;
    }
}
```

### UserRepository - FindNearbyLocalSupporters Method

[Source: architecture/11-architecture-backend-laravel.md#11.3]

**File Location:** `app/Repositories/Eloquent/UserRepository.php`

**Implementation:**

```php
<?php

namespace App\Repositories\Eloquent;

use App\Models\User;
use App\Repositories\Contracts\UserRepositoryInterface;
use Illuminate\Database\Eloquent\Collection;
use Illuminate\Support\Facades\DB;

class UserRepository implements UserRepositoryInterface
{
    public function __construct(
        private readonly User $model
    ) {}

    /**
     * Find Local Supporters with notification zones covering the given location
     */
    public function findNearbyLocalSupporters(
        float $latitude,
        float $longitude
    ): Collection {
        return $this->model
            ->where('user_type', 'local_supporter')
            ->whereNotNull('fcm_token')
            ->whereNotNull('notification_zone_lat')
            ->whereNotNull('notification_zone_lng')
            ->whereNotNull('notification_zone_radius')
            ->whereRaw("
                ST_Distance_Sphere(
                    ST_SRID(POINT(notification_zone_lng, notification_zone_lat), 4326),
                    ST_SRID(POINT(?, ?), 4326)
                ) <= notification_zone_radius * 1000
            ", [$longitude, $latitude])
            ->get();
    }
}
```

### NotificationService - Daily Limit Tracking

**Enhanced NotificationService:**

```php
<?php

namespace App\Services;

use App\Models\Notification;
use Illuminate\Support\Carbon;
use Illuminate\Support\Str;

class NotificationService
{
    // ... existing methods ...

    /**
     * Get count of notifications sent to user today for specific type
     */
    public function getDailyNotificationCount(int $userId, string $type): int
    {
        return Notification::where('user_id', $userId)
            ->where('type', $type)
            ->whereDate('created_at', Carbon::today())
            ->count();
    }

    /**
     * Check if user can receive notification (under daily limit)
     */
    public function canReceiveNotification(
        int $userId,
        string $type,
        int $maxDaily = 5
    ): bool {
        $count = $this->getDailyNotificationCount($userId, $type);
        return $count < $maxDaily;
    }
}
```

```dart
  State<NotificationZonePage> createState() => _NotificationZonePageState();

class _NotificationZonePageState extends State<NotificationZonePage> {
  GoogleMapController? _mapController;
  LatLng _center = const LatLng(35.6762, 139.6503); // Tokyo default
  double _radiusKm = 10.0;

  Set<Marker> _markers = {};

  @override
  void initState() {
    super.initState();
    _updateCircle();

    setState(() {
      _circles = {
        Circle(
          circleId: const CircleId('notification_zone'),
          center: _center,
          radius: _radiusKm * 1000, // Convert km to meters
          strokeWidth: 2,
          strokeColor: Theme.of(context).primaryColor,
          fillColor: Theme.of(context).primaryColor.withOpacity(0.2),
        ),
      };
    });

    setState(() {
      _markers = {
        Marker(
          markerId: const MarkerId('zone_center'),
          position: _center,
          draggable: true,
          onDragEnd: (newPosition) {
            setState(() {
              _center = newPosition;
              _updateCircle();
            });
          },
        ),
      };
    });
  }

    try {
      final position = await Geolocator.getCurrentPosition();
      setState(() {
        _center = LatLng(position.latitude, position.longitude);
        _updateCircle();
        _updateMarker();

        CameraUpdate.newLatLng(_center),

          content: Text('Impossible d\'obtenir votre position'),

      );

        latitude: _center.latitude,
        longitude: _center.longitude,
        radiusKm: _radiusKm.round(),

              child: const Text('Enregistrer'),
```

### NotificationZoneBloc Implementation

**File Location:** `lib/features/settings/presentation/bloc/notification_zone_bloc.dart`

```dart
import 'package:flutter_bloc/flutter_bloc.dart';
import 'package:equatable/equatable.dart';

// Events
abstract class NotificationZoneEvent extends Equatable {
  @override
  List<Object?> get props => [];
}

class LoadNotificationZone extends NotificationZoneEvent {}

class SaveNotificationZone extends NotificationZoneEvent {
  final double latitude;
  final double longitude;
  final int radiusKm;

  SaveNotificationZone({
    required this.latitude,
    required this.longitude,
    required this.radiusKm,
  });

  @override
  List<Object?> get props => [latitude, longitude, radiusKm];
}

// States
abstract class NotificationZoneState extends Equatable {
  @override
  List<Object?> get props => [];
}

class NotificationZoneInitial extends NotificationZoneState {}

class NotificationZoneLoading extends NotificationZoneState {}

class NotificationZoneLoaded extends NotificationZoneState {
  final double? latitude;
  final double? longitude;
  final int? radiusKm;

  NotificationZoneLoaded({
    this.latitude,
    this.longitude,
    this.radiusKm,
  });

  @override
  List<Object?> get props => [latitude, longitude, radiusKm];
}

class NotificationZoneSaving extends NotificationZoneState {}

class NotificationZoneSaved extends NotificationZoneState {}

class NotificationZoneError extends NotificationZoneState {
  final String message;

  NotificationZoneError(this.message);

  @override
  List<Object?> get props => [message];
}

// Bloc
class NotificationZoneBloc extends Bloc<NotificationZoneEvent, NotificationZoneState> {
  final SettingsRepository _settingsRepository;

  NotificationZoneBloc({
    required SettingsRepository settingsRepository,
  })  : _settingsRepository = settingsRepository,
        super(NotificationZoneInitial()) {
    on<LoadNotificationZone>(_onLoadZone);
    on<SaveNotificationZone>(_onSaveZone);
  }

  Future<void> _onLoadZone(
    LoadNotificationZone event,
    Emitter<NotificationZoneState> emit,
  ) async {
    emit(NotificationZoneLoading());

    try {
      final zone = await _settingsRepository.getNotificationZone();
      emit(NotificationZoneLoaded(
        latitude: zone['latitude'],
        longitude: zone['longitude'],
        radiusKm: zone['radius_km'],
      ));
    } catch (e) {
      emit(NotificationZoneError('Erreur de chargement de la zone'));
    }
  }

  Future<void> _onSaveZone(
    SaveNotificationZone event,
    Emitter<NotificationZoneState> emit,
  ) async {
    emit(NotificationZoneSaving());

    try {
      await _settingsRepository.setNotificationZone(
        latitude: event.latitude,
        longitude: event.longitude,
        radiusKm: event.radiusKm,
      );
      emit(NotificationZoneSaved());
    } catch (e) {
      emit(NotificationZoneError('Erreur d\'enregistrement de la zone'));
    }
  }
}
```

### Error Handling Strategy

[Source: architecture/18-stratégie-de-gestion-derreurs.md]

**Backend Error Scenarios:**
- Invalid coordinates (latitude/longitude out of range) - return 422
- Spatial query timeout (large number of users) - optimize with indexes
- Daily limit calculation error - log and use safe default (allow notification)
- FCM send failure for multiple users - continue sending to remaining users

**Frontend Error Scenarios:**
- Map fails to load - show error message, offer retry
- Current location unavailable - show message, allow manual selection
- Save zone fails - show error, allow retry
- Invalid radius selected - validate before save

**User-Friendly Error Messages:**
- Map error: "Impossible de charger la carte. Vérifiez votre connexion."
- Location error: "Impossible d'obtenir votre position. Sélectionnez manuellement."
- Save error: "Erreur d'enregistrement. Réessayez."
- Coordinate error: "Coordonnées invalides. Sélectionnez une zone valide."

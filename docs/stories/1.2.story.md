## Story

**En tant qu'** utilisateur,
**Je veux** pouvoir me connecter avec mon compte Google,
**Afin d'** accéder rapidement à l'application sans créer un nouveau compte.

---

## Acceptance Criteria

1. L'écran de login affiche un bouton "Continuer avec Google" clairement visible
2. Le flux OAuth Google s'ouvre dans un navigateur sécurisé (pas WebView)
3. Après autorisation Google, l'utilisateur est redirigé vers l'app avec un token valide
4. Le backend crée automatiquement un compte utilisateur à la première connexion
5. Le token d'authentification est stocké de manière sécurisée sur l'appareil
6. Les connexions suivantes utilisent le token stocké sans redemander l'autorisation
7. Un message d'erreur clair s'affiche si l'authentification échoue
8. L'endpoint `/api/auth/google` accepte le token Google et retourne un token Sanctum

### Google OAuth 2.0 Integration

[Source: architecture/7-apis-externes.md#7.1]

**API Details:**
- **Base URL:** https://oauth2.googleapis.com
- **Authentication:** OAuth 2.0 ID Token
- **Rate Limits:** 10,000 requests/day (free tier)
- **Documentation:** https://developers.google.com/identity

**Endpoints Used:**
- `GET /tokeninfo?id_token={token}` - Validate ID token and get user info
- Returns: `{sub, email, name, picture, aud, exp, ...}`

**Integration Notes:**
- Use Laravel Socialite to simplify OAuth integration
- ID token must be validated server-side for security
- Verify token audience (aud) matches GOOGLE_CLIENT_ID
- Google returns unique user ID in `sub` field (use as provider_id)

### API Endpoint Specification

[Source: architecture/5-spécification-api-rest.md#5.3.2]

**Endpoint:** `POST /api/auth/google`

**Request Body:**
```json
{
  "id_token": "google_id_token_here"
}
```

**Validation Rules:**
- `id_token`: required, string

**Success Response (200 OK):**
```json
{
  "user": {
    "id": 1,
    "email": "user@gmail.com",
    "name": "John Doe",
    "avatar_url": "https://lh3.googleusercontent.com/...",
    "user_type": "traveler",
    "trust_score": 0.00,
    "is_new": true
  },
  "token": "1|sanctum_token_here",
  "is_new_user": true
}
```

**Error Responses:**
- `401 Unauthorized` - Invalid Google token
- `403 Forbidden` - User is banned
- `422 Validation Error` - Missing or invalid id_token
- `500 Server Error` - Internal server error

**Error Format:**
```json
{
  "error": {
    "code": "INVALID_TOKEN",
    "message": "Le token Google est invalide",
    "timestamp": "2026-01-31T10:00:00Z"
  }
}
```

### Backend AuthService Implementation

[Source: architecture/11-architecture-backend-laravel.md#11.4]

**File Location:** `app/Services/AuthService.php`

**Key Methods:**

```php
public function authenticateWithGoogle(string $idToken): array
{
    // 1. Validate token with Google
    $response = Http::get('https://oauth2.googleapis.com/tokeninfo', [
        'id_token' => $idToken,
    ]);

    if ($response->failed()) {
        throw new \InvalidArgumentException('Invalid Google token');
    }

    $googleUser = $response->json();

    // 2. Verify audience (client ID)
    if ($googleUser['aud'] !== config('services.google.client_id')) {
        throw new \InvalidArgumentException('Invalid token audience');
    }

    // 3. Find or create user
    return $this->findOrCreateUser(
        provider: 'google',
        providerId: $googleUser['sub'],
        email: $googleUser['email'],
        name: $googleUser['name'] ?? 'Utilisateur',
        avatarUrl: $googleUser['picture'] ?? null
    );
}

private function findOrCreateUser(
    string $provider,
    string $providerId,
    string $email,
    string $name,
    ?string $avatarUrl
): array {
    $isNewUser = false;

    // Find by provider + provider_id
    $user = User::where('provider', $provider)
        ->where('provider_id', $providerId)
        ->first();

    if (!$user) {
        // Check email conflicts
        $existingUser = User::where('email', $email)->first();
        if ($existingUser) {
            throw new \InvalidArgumentException(
                'Un compte existe déjà avec cet email via un autre fournisseur'
            );
        }

        // Create new user
        $user = User::create([
            'email' => $email,
            'name' => $name,
            'avatar_url' => $avatarUrl,
            'provider' => $provider,
            'provider_id' => $providerId,
            'user_type' => 'traveler',
        ]);

        $isNewUser = true;
    }

    // Check ban status
    if ($user->is_banned) {
        throw new \InvalidArgumentException('Ce compte a été suspendu');
    }

    // Create Sanctum token
    $token = $user->createToken('mobile-app');

    return [
        'user' => $user,
        'token' => $token->plainTextToken,
        'is_new_user' => $isNewUser,
    ];
}
```

### Database Schema

[Source: architecture/9-schéma-de-base-de-données.md]

**Users Table Fields Required:**
- `id` - BIGINT UNSIGNED PRIMARY KEY
- `email` - VARCHAR(255) UNIQUE NOT NULL
- `name` - VARCHAR(100) NOT NULL
- `avatar_url` - VARCHAR(500) NULL
- `provider` - ENUM('google', 'apple') NOT NULL
- `provider_id` - VARCHAR(255) NOT NULL
- `user_type` - ENUM('traveler', 'local_supporter') DEFAULT 'traveler'
- `trust_score` - DECIMAL(3,2) DEFAULT 0.00
- `is_new` - BOOLEAN DEFAULT TRUE
- `is_banned` - BOOLEAN DEFAULT FALSE
- `created_at`, `updated_at` - TIMESTAMP

**Indexes:**
- UNIQUE INDEX on (provider, provider_id)
- INDEX on email

**Personal Access Tokens Table** (Laravel Sanctum):
- Created automatically by Sanctum migration
- Stores API tokens for authenticated users

### Error Handling Strategy

[Source: architecture/18-stratégie-de-gestion-derreurs.md]

**Backend Error Codes:**
- `INVALID_TOKEN` - Google token validation failed
- `TOKEN_AUDIENCE_MISMATCH` - Client ID doesn't match
- `EMAIL_CONFLICT` - Email already exists with different provider
- `USER_BANNED` - Account has been suspended

**Frontend Error Messages (User-Friendly):**
- Google Sign-In cancellation: "Connexion annulée"
- Network error: "Erreur de connexion. Vérifiez votre connexion internet."
- Invalid token: "Erreur d'authentification. Veuillez réessayer."
- Banned user: "Votre compte a été suspendu. Contactez le support."

### Security Considerations

[Source: architecture/15-sécurité-et-performance.md]

**Critical Security Rules:**
1. **NEVER** validate Google tokens client-side only - always validate server-side
2. **NEVER** trust client-provided user data - extract from validated token only
3. **ALWAYS** verify token audience matches your client_id
4. **ALWAYS** check token expiration
5. **ALWAYS** use HTTPS for all API calls
6. **STORE** tokens in secure storage (flutter_secure_storage), never SharedPreferences

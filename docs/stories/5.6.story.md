### App Signing and Security Tasks

- [ ] **Task 4: Generate upload keystore** (AC: 1)
  - [ ] Create keystore directory:
    ```bash
    mkdir -p ~/keystores
    cd ~/keystores
    ```
  - [ ] Generate upload keystore:
    ```bash
    keytool -genkey -v -keystore upload-keystore.jks \
      -keyalg RSA -keysize 2048 -validity 10000 \
      -alias travelconnect
    ```
  - [ ] Enter keystore password (save securely)
  - [ ] Enter key password (save securely)
  - [ ] Fill in organization details:
    - Name: TravelConnect
    - Organizational Unit: Development
    - Organization: TravelConnect
    - City: Tokyo
    - State: Tokyo
    - Country: JP
  - [ ] Store keystore file securely (backup in multiple locations)
  - [ ] Document keystore credentials in password manager

- [ ] **Task 5: Configure app signing in Android project** (AC: 1)
  - [ ] Create `android/key.properties` file:
    ```properties
    storePassword=YOUR_KEYSTORE_PASSWORD
    keyPassword=YOUR_KEY_PASSWORD
    keyAlias=travelconnect
    storeFile=/path/to/upload-keystore.jks
    ```
  - [ ] Add `key.properties` to `.gitignore`:
    ```
    # Keystore files
    *.jks
    *.keystore
    key.properties
    ```
  - [ ] Update `android/app/build.gradle` to load signing config
  - [ ] Verify keystore path is correct

- [ ] **Task 6: Update build.gradle for release** (AC: 1)
  - [ ] Edit `android/app/build.gradle`
  - [ ] Add signing config loading:
    ```gradle
    def keystoreProperties = new Properties()
    def keystorePropertiesFile = rootProject.file('key.properties')
    if (keystorePropertiesFile.exists()) {
        keystoreProperties.load(new FileInputStream(keystorePropertiesFile))
    }
    ```
  - [ ] Configure signing in android block:
    ```gradle
    signingConfigs {
        release {
            keyAlias keystoreProperties['keyAlias']
            keyPassword keystoreProperties['keyPassword']
            storeFile keystoreProperties['storeFile'] ? file(keystoreProperties['storeFile']) : null
            storePassword keystoreProperties['storePassword']
        }
    }
    buildTypes {
        release {
            signingConfig signingConfigs.release
            minifyEnabled true
            shrinkResources true
            proguardFiles getDefaultProguardFile('proguard-android-optimize.txt'), 'proguard-rules.pro'
        }
    }
    ```
  - [ ] Update version code and version name
  - [ ] Set minimum SDK version to 21 (Android 5.0)

### Data Safety Declaration

**Data Collection and Security:**

1. **Location (Approximate):**
   - Purpose: App functionality
   - Optional: No (required for core features)
   - Collected: Yes
   - Shared: No
   - Encrypted: Yes

2. **Personal info (Email address, Name):**
   - Purpose: App functionality, Account management
   - Optional: No
   - Collected: Yes (via Google Sign-In)
   - Shared: No
   - Encrypted: Yes

3. **Photos and videos:**
   - Purpose: App functionality (profile picture)
   - Optional: Yes
   - Collected: Yes
   - Shared: No
   - Encrypted: Yes

4. **App activity (User-generated content):**
   - Purpose: App functionality
   - Optional: No
   - Collected: Yes (questions, answers)
   - Shared: Yes (publicly visible to other users)
   - Encrypted: Yes

5. **Device or other IDs:**
   - Purpose: App functionality, Analytics
   - Optional: No
   - Collected: Yes
   - Shared: No
   - Encrypted: Yes

**Security practices:**
- Data is encrypted in transit using HTTPS

### Keystore Security Best Practices

**Critical Security Measures:**

1. **Backup Keystore:**
   - Store in secure password manager
   - Keep offline backup on encrypted USB drive
   - Store in secure cloud storage (encrypted)
   - NEVER commit to Git

2. **Password Security:**
   - Use strong passwords (20+ characters)
   - Store passwords in password manager only
   - Never share keystore or passwords
   - Different passwords for keystore and key

3. **Access Control:**
   - Limit who has access to keystore
   - Document keystore owner/custodian
   - Plan for key rotation (if compromised)

4. **Loss Prevention:**
   - If keystore is lost, app cannot be updated
   - Google Play App Signing can mitigate this
   - Consider enrolling in Google Play App Signing

## Story

**En tant qu'** auteur d'une question,
**Je veux** recevoir une notification quand quelqu'un répond,
**Afin de** ne pas manquer les conseils reçus.

---

## Acceptance Criteria

1. Une notification push est envoyée à l'auteur quand une réponse est postée
2. La notification contient : "Nouvelle réponse à [titre question]" + aperçu
3. Cliquer sur la notification ouvre le détail de la question
4. Les notifications sont envoyées même si l'app est fermée
5. L'utilisateur peut désactiver ce type de notification dans les paramètres

### Event-Driven Architecture

[Source: architecture/11-architecture-backend-laravel.md#11.1]

**Event-Listener Pattern:**
Laravel uses event-driven architecture for decoupled notification handling. When an answer is created, an event is dispatched, and listeners handle the notification logic.

**File Locations:**
- Events: `app/Events/AnswerCreated.php`
- Listeners: `app/Listeners/SendNewAnswerNotification.php`
- Registration: `app/Providers/EventServiceProvider.php`

**Event Dispatch:**
```php
// In AnswerController or AnswerService after creating answer
event(new AnswerCreated($answer));
```

**Event Class Structure:**
```php
<?php

namespace App\Events;

use App\Models\Answer;
use Illuminate\Foundation\Events\Dispatchable;
use Illuminate\Queue\SerializesModels;

class AnswerCreated
{
    use Dispatchable, SerializesModels;

    public Answer $answer;
    public $question;
    public $author;

    public function __construct(Answer $answer)
    {
        $this->answer = $answer;
        $this->question = $answer->question;
        $this->author = $answer->user;
    }
}
```

### SendNewAnswerNotification Listener Implementation

[Source: architecture/11-architecture-backend-laravel.md#11.1]

**File Location:** `app/Listeners/SendNewAnswerNotification.php`

**Complete Implementation:**

```php
<?php

namespace App\Listeners;

use App\Events\AnswerCreated;
use App\Services\FCMService;
use App\Services\NotificationService;
use Illuminate\Contracts\Queue\ShouldQueue;
use Illuminate\Queue\InteractsWithQueue;
use Illuminate\Support\Facades\Log;

class SendNewAnswerNotification implements ShouldQueue
{
    use InteractsWithQueue;

    public function __construct(
        private readonly FCMService $fcmService,
        private readonly NotificationService $notificationService
    ) {}

    public function handle(AnswerCreated $event): void
    {
        $answer = $event->answer;
        $question = $event->question;
        $questionAuthor = $question->user;
        $answerAuthor = $event->author;

        // Don't notify if user answers their own question
        if ($questionAuthor->id === $answerAuthor->id) {
            Log::info('Skipping self-answer notification', [
                'question_id' => $question->id,
                'user_id' => $questionAuthor->id,
            ]);
            return;
        }

        // Check if user has FCM token
        if (!$questionAuthor->fcm_token) {
            Log::info('User has no FCM token', [
                'user_id' => $questionAuthor->id,
            ]);
            return;
        }

        // Check notification preferences
        $settings = $questionAuthor->notification_settings ?? [];
        if (isset($settings['new_answers']) && $settings['new_answers'] === false) {
            Log::info('User disabled new answer notifications', [
                'user_id' => $questionAuthor->id,
            ]);
            return;
        }

        // Build notification payload
        $title = 'Nouvelle réponse';
        $body = sprintf(
            '%s a répondu à "%s"',
            $answerAuthor->name,
            $this->truncate($question->title, 50)
        );

        $data = [
            'type' => 'new_answer',
            'question_id' => (string) $question->id,
            'answer_id' => (string) $answer->id,
        ];

        // Send push notification
        $sent = $this->fcmService->sendNotification(
            fcmToken: $questionAuthor->fcm_token,
            notification: ['title' => $title, 'body' => $body],
            data: $data
        );

        if ($sent) {
            // Create notification record in database
            $this->notificationService->createNotification(
                userId: $questionAuthor->id,
                type: 'new_answer',
                title: $title,
                body: $body,
                data: $data
            );

            Log::info('New answer notification sent', [
                'question_id' => $question->id,
                'answer_id' => $answer->id,
                'recipient_id' => $questionAuthor->id,
            ]);
        }
    }

    private function truncate(string $text, int $length): string
    {
        return strlen($text) > $length
            ? substr($text, 0, $length) . '...'
            : $text;
    }
}
```

### NotificationService Implementation

[Source: architecture/11-architecture-backend-laravel.md#11.1]

**File Location:** `app/Services/NotificationService.php`

**Key Methods:**

```php
<?php

namespace App\Services;

use App\Models\Notification;
use Illuminate\Support\Str;

class NotificationService
{
    /**
     * Create notification record in database
     */
    public function createNotification(
        int $userId,
        string $type,
        string $title,
        string $body,
        array $data = []
    ): Notification {
        return Notification::create([
            'id' => Str::uuid(),
            'user_id' => $userId,
            'type' => $type,
            'title' => $title,
            'body' => $body,
            'data' => $data,
            'read_at' => null,
        ]);
    }

    /**
     * Get unread notification count for user
     */
    public function getUnreadCount(int $userId): int
    {
        return Notification::where('user_id', $userId)
            ->whereNull('read_at')
            ->count();
    }

    /**
     * Mark notification as read
     */
    public function markAsRead(string $notificationId): bool
    {
        return Notification::where('id', $notificationId)
            ->update(['read_at' => now()]);
    }

    /**
     * Mark all notifications as read for user
     */
    public function markAllAsRead(int $userId): int
    {
        return Notification::where('user_id', $userId)
            ->whereNull('read_at')
            ->update(['read_at' => now()]);
    }
}
```

### Database Schema

[Source: architecture/9-schéma-de-base-de-données.md]

**Notifications Table:**
```sql
CREATE TABLE notifications (
    id CHAR(36) PRIMARY KEY,
    user_id BIGINT UNSIGNED NOT NULL,
    type VARCHAR(50) NOT NULL,
    title VARCHAR(255) NOT NULL,
    body TEXT NOT NULL,
    data JSON NULL,
    read_at TIMESTAMP NULL,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,

    FOREIGN KEY (user_id) REFERENCES users(id) ON DELETE CASCADE,
    INDEX idx_user_read (user_id, read_at),
    INDEX idx_user_created (user_id, created_at DESC)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci;
```

### Frontend Notification Navigation

[Source: architecture/10-architecture-frontend-flutter.md]

**Enhanced NotificationService with Navigation:**

```dart
class NotificationService {
  final FirebaseMessaging _firebaseMessaging = FirebaseMessaging.instance;
  final FlutterLocalNotificationsPlugin _localNotifications;
  final ApiClient _apiClient;
  final GlobalKey<NavigatorState> navigatorKey;

  NotificationService(
    this._apiClient,
    this.navigatorKey,
  ) : _localNotifications = FlutterLocalNotificationsPlugin();

  // ... existing methods ...

  void _handleNotificationTap(RemoteMessage message) {
    print('Notification tapped: ${message.data}');

    final data = message.data;
    final type = data['type'] as String?;

    if (type == 'new_answer' && data.containsKey('question_id')) {
      _navigateToQuestion(int.parse(data['question_id']));
    }
  }

  void _navigateToQuestion(int questionId) {
    // Use navigator key to navigate even when app was terminated
    navigatorKey.currentState?.pushNamed(
      '/question/$questionId',
    );

    // Or use GoRouter if configured
    // context.go('/question/$questionId');
  }

  void _onNotificationTapped(NotificationResponse response) {
    if (response.payload != null) {
      final data = json.decode(response.payload!);
      if (data['question_id'] != null) {
        _navigateToQuestion(int.parse(data['question_id']));
      }
    }
  }
}
```

### Queue Configuration for Listeners

[Source: architecture/11-architecture-backend-laravel.md]

**Queue Setup:**
The `SendNewAnswerNotification` listener implements `ShouldQueue` to run asynchronously. This prevents blocking the answer creation response.

**Configure Queue Driver in .env:**
```env
QUEUE_CONNECTION=database
```

**Run Queue Worker:**
```bash
php artisan queue:work
```

**For Production:**
Use Supervisor or systemd to keep queue worker running continuously.

### Error Handling Strategy

[Source: architecture/18-stratégie-de-gestion-derreurs.md]

**Backend Error Scenarios:**
- FCM token invalid (log warning, don't fail request)
- Firebase service unavailable (retry with exponential backoff)
- Notification preferences not set (use default values)
- Database error creating notification record (log error, send push anyway)

**Frontend Error Scenarios:**
- Navigation fails (show error message, fallback to notifications list)
- Question not found (show "Question supprimée" message)
- Network error loading question (show retry button)

**User-Friendly Error Messages:**
- Navigation failed: "Impossible d'ouvrir la question. Réessayez."
- Question deleted: "Cette question n'existe plus."
- Network error: "Erreur de connexion. Vérifiez votre connexion internet."

## Story

**En tant qu'** utilisateur,
**Je veux** pouvoir poster une question liée à un lieu,
**Afin d'** obtenir des conseils de locaux ou voyageurs expérimentés.

---

## Acceptance Criteria

1. Un bouton flottant (FAB) "+" est toujours visible sur la carte
2. Cliquer sur le FAB ouvre un formulaire de nouvelle question
3. Le formulaire contient : titre (obligatoire, max 100 car.), description (max 500 car.)
4. La localisation est pré-remplie avec la position actuelle
5. L'utilisateur peut ajuster la localisation en déplaçant un marqueur sur une mini-carte
6. Un bouton "Publier" envoie la question
7. Une confirmation visuelle s'affiche après publication réussie
8. La nouvelle question apparaît immédiatement sur la carte
9. L'endpoint POST `/api/questions` crée une nouvelle question
10. Les champs titre et localisation sont validés côté serveur

    {
        $cacheKey = "geocode:{$lat}:{$lng}";

        return Cache::remember($cacheKey, now()->addDays(30), function () use ($lat, $lng) {
            $response = Http::get('https://maps.googleapis.com/maps/api/geocode/json', [
                'latlng' => "{$lat},{$lng}",
                'key' => config('services.google_maps.api_key'),
                'language' => 'ja',
            ]);

            if ($response->successful() && !empty($response['results'])) {
                $result = $response['results'][0];
                return [
                    'formatted_address' => $result['formatted_address'],
                    'city' => $this->extractCity($result['address_components']),
                ];
            }

            return [
                'formatted_address' => "{$lat}, {$lng}",
                'city' => null,
            ];
        });
    }

### Google Maps Geocoding API

[Source: architecture/7-apis-externes.md#7.4]

**Reverse Geocoding:**
- Convert coordinates to human-readable address
- API Endpoint: `https://maps.googleapis.com/maps/api/geocode/json`
- Parameters:
  - `latlng`: Coordinates (e.g., "35.6595,139.7004")
  - `key`: API key
  - `language`: Preferred language (e.g., "ja" for Japanese)

**Response Structure:**
```json
{
  "results": [
    {
      "formatted_address": "Shibuya, Tokyo, Japan",
      "address_components": [
        {
          "long_name": "Shibuya",
          "short_name": "Shibuya",
          "types": ["sublocality", "political"]
        },
        {
          "long_name": "Tokyo",
          "short_name": "Tokyo",
          "types": ["locality", "political"]
        }
      ]
    }
  ]
}
```

**Caching Strategy:**
- Cache results in Redis with key: `geocode:{lat}:{lng}`
- TTL: 30 days (addresses rarely change)
- Reduces API calls and improves performance
- Saves costs (Geocoding API charges after free tier)

**Cost Optimization:**
- Free tier: $200/month credit (~40,000 requests)
- Beyond free tier: $5 per 1,000 requests
- Caching reduces cost by ~90%

### Backend Service Layer

[Source: architecture/11-architecture-backend-laravel.md#11.4]

**QuestionService Implementation:**
```php
class QuestionService
{
    public function __construct(
        private readonly QuestionRepository $questionRepository,
        private readonly GeocodingService $geocodingService
    ) {}

    public function createQuestion(User $user, array $data): Question
    {
        // Reverse geocode to get location name
        $locationData = $this->geocodingService->reverseGeocode(
            $data['latitude'],
            $data['longitude']
        );

        // Create question with spatial point
        $question = $user->questions()->create([
            'title' => $data['title'],
            'description' => $data['description'] ?? null,
            'latitude' => $data['latitude'],
            'longitude' => $data['longitude'],
            'location' => DB::raw(
                "ST_SRID(POINT({$data['longitude']}, {$data['latitude']}), 4326)"
            ),
            'location_name' => $locationData['formatted_address'],
            'city' => $locationData['city'],
        ]);

        // Fire event for notifications (Epic 4)
        event(new QuestionCreated($question));

        // Invalidate nearby questions cache
        $this->invalidateNearbyQuestionsCache(
            $data['latitude'],
            $data['longitude']
        );

        return $question->load('user');
    }

    private function invalidateNearbyQuestionsCache(float $lat, float $lng): void
    {
        // Invalidate cache for surrounding areas (±0.1 degrees ~ 10km)
        for ($latOffset = -0.1; $latOffset <= 0.1; $latOffset += 0.05) {
            for ($lngOffset = -0.1; $lngOffset <= 0.1; $lngOffset += 0.05) {
                $cacheKey = sprintf(
                    'questions:nearby:%.2f:%.2f:*',
                    $lat + $latOffset,
                    $lng + $lngOffset
                );
                Cache::forget($cacheKey);
            }
        }
    }
}
```

### Optimistic Updates

**Strategy:**
- Create question optimistically on frontend
- Add to MapBloc questions list immediately
- Show new marker on map
- Animate camera to new question
- If API call fails, remove question and show error
- If API succeeds, update question with server-generated ID

**Implementation:**
```dart
// In CreateQuestionBloc
Future<void> _onSubmitQuestion(
  SubmitQuestion event,
  Emitter<CreateQuestionState> emit,
) async {
  emit(CreateQuestionSubmitting());

  // Create temporary question for optimistic update
  final tempQuestion = Question(
    id: -1, // Temporary ID
    title: _title,
    description: _description,
    latitude: _latitude,
    longitude: _longitude,
    answersCount: 0,
    createdAt: DateTime.now(),
    user: _currentUser,
  );

  // Add to map immediately
  _mapBloc.add(AddQuestionOptimistic(tempQuestion));

  // Call API
  final result = await _createQuestion(CreateQuestionParams(...));

  result.fold(
    (failure) {
      // Remove optimistic question on failure
      _mapBloc.add(RemoveQuestionOptimistic(tempQuestion));
      emit(CreateQuestionError(failure.message));
    },
    (question) {
      // Replace temporary question with real one
      _mapBloc.add(ReplaceQuestionOptimistic(tempQuestion, question));
      emit(CreateQuestionSuccess(question));
    },
  );
}
```

### Rate Limiting

**Backend Rate Limit:**
- 10 questions per hour per user
- Prevents spam and abuse
- Uses Laravel rate limiter
- Configuration in RouteServiceProvider:

      return Limit::perHour(10)->by($request->user()?->id);

### Security Considerations

**Input Sanitization:**
- Sanitize title and description on backend
- Prevent XSS attacks
- Strip HTML tags (use strip_tags)
- Escape special characters for database

**Location Validation:**
- Validate coordinates are within Earth bounds
- Prevent injection via coordinates
- Use prepared statements for spatial queries

**Authorization:**
- Verify user is authenticated (auth:sanctum middleware)
- Check user is not banned (not.banned middleware)
- Verify user owns the question (for future updates/deletes)

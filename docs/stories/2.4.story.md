## Story

**En tant qu'** utilisateur,
**Je veux** voir le détail complet d'une question,
**Afin de** comprendre le contexte et lire les réponses.

---

## Acceptance Criteria

1. L'écran détail affiche : titre, description, localisation sur mini-carte
2. L'auteur est affiché avec sa photo, nom, badge et score de confiance
3. La date de publication est affichée en format relatif ("il y a 2h")
4. Le nombre de réponses est indiqué
5. La liste des réponses s'affiche sous la question (voir Epic 3)
6. Un bouton "Répondre" est visible en bas de l'écran
7. L'endpoint GET `/api/questions/{id}` retourne la question avec ses réponses

    ```php
    public function getQuestionWithAnswers(int $id, User $currentUser): Question
    {
        $question = Question::with([
            'user',
            'answers' => function ($query) use ($currentUser) {
                $query->where('is_deleted', false)
                    ->with(['user', 'ratings' => function ($q) use ($currentUser) {
                        $q->where('user_id', $currentUser->id);
                    }])
                    ->orderByDesc('average_rating')
                    ->orderByDesc('created_at');
            }
        ])->findOrFail($id);

        // Mark as read if user is the author
        if ($question->user_id === $currentUser->id && $question->has_unread_answers) {
            $question->update(['has_unread_answers' => false]);
        }

        return $question;
    }
    ```

- Has many Ratings

### Relative Time Formatting

**Package:** `timeago: ^3.6.0`

**French Locale Configuration:**
```dart
import 'package:timeago/timeago.dart' as timeago;

void main() {
  timeago.setLocaleMessages('fr', timeago.FrMessages());
  runApp(MyApp());
}
```

**Usage:**
```dart
final relative = timeago.format(question.createdAt, locale: 'fr');
// Examples:
// - "à l'instant" (0-59 seconds)
// - "il y a une minute" (1 minute)
// - "il y a 5 minutes" (2-59 minutes)
// - "il y a une heure" (1 hour)
// - "il y a 3 heures" (2-23 hours)
// - "il y a un jour" (1 day)
// - "il y a 3 jours" (2-6 days)
// - "il y a une semaine" (7 days)
```

**Custom Formatting for Dates > 7 days:**
```dart
String formatRelativeTime(DateTime dateTime) {
  final now = DateTime.now();
  final difference = now.difference(dateTime);

  if (difference.inDays > 7) {
    // Use date format: "15 janvier"
    return DateFormat('d MMMM', 'fr').format(dateTime);
  } else {
    return timeago.format(dateTime, locale: 'fr');
  }
}
```

### Trust Score Display

**Formatting:**
- Display with 1 decimal place: `3.5`
- Show star icon next to score
- Color: Amber/Gold
- Font: Medium size, readable

**Trust Score Ranges:**
- 0.0 - 1.9: New user / Low trust (grey star)
- 2.0 - 3.4: Average trust (amber star)
- 3.5 - 4.4: Good trust (amber star, bold)
- 4.5 - 5.0: Excellent trust (gold star, bold)

**Special Cases:**
- If trust_score = 0.00 AND user is new (is_new = true): Display "Nouveau" instead of score
- If trust_score = null: Display "—" or hide

### Answer Sorting Logic

[Source: architecture/11-architecture-backend-laravel.md]

**Sorting Priority:**
1. **Average Rating** (DESC) - Higher rated answers first
2. **Created At** (DESC) - Newer answers first if ratings are equal

**SQL Query:**
```php
$answers = $question->answers()
    ->where('is_deleted', false)
    ->orderByDesc('average_rating')
    ->orderByDesc('created_at')
    ->get();
```

**Reasoning:**
- Users want to see the most helpful answers first
- Average rating is the best indicator of quality
- Recent answers are prioritized when quality is equal
- Deleted answers are excluded

### Error Handling

**Error Scenarios:**

1. **Question Not Found (404):**
   - Show "Cette question n'existe plus" message
   - Provide "Retour" button to navigate back

2. **Network Error:**
   - Show "Erreur de connexion" message
   - Provide "Réessayer" button
   - Keep showing cached data if available

3. **Unauthorized (401):**
   - Redirect to login screen
   - Show "Session expirée" message

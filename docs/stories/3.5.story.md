## Story

**En tant qu'** utilisateur,
**Je veux** pouvoir signaler un contenu inapproprié,
**Afin de** maintenir une communauté saine.

## Acceptance Criteria

1. Un bouton "Signaler" (icône drapeau) est accessible sur chaque question et réponse
2. Cliquer ouvre un menu avec les raisons : Spam, Contenu offensant, Information fausse, Autre
3. L'utilisateur peut ajouter un commentaire optionnel
4. Une confirmation s'affiche après le signalement
5. Le contenu signalé est marqué pour revue dans l'admin
6. L'endpoint POST `/api/reports` crée un signalement
7. Un utilisateur ne peut signaler le même contenu qu'une fois

### Report Model Specification

[Source: architecture/4-modèles-de-données.md#4.5]

**Report Model Attributes:**
- `id`: bigint - Unique identifier
- `reporter_id`: bigint - User who reported (FK)
- `reportable_type`: string - Type of content (Question, Answer)
- `reportable_id`: bigint - ID of reported content
- `reason`: enum - spam, offensive, false_info, other
- `comment`: text|null - Optional comment (max 500 characters)
- `status`: enum - pending, approved, rejected
- `admin_note`: text|null - Admin's note on the report
- `processed_at`: timestamp|null - When admin processed it
- `processed_by`: bigint|null - Admin who processed (FK)
- `created_at`, `updated_at`: timestamp

**Relationships:**
- Belongs to User (reporter)
- Morphs to Question or Answer (reportable)
- Belongs to Admin (processed_by)

**Unique Constraint:** (reporter_id, reportable_type, reportable_id) - one report per user per content

### API Endpoint Specification

[Source: architecture/5-spécification-api-rest.md#5.3.6]

**Endpoint:** `POST /api/reports`

**Authentication:** Required (Bearer token)

**Request Body:**
```json
{
  "reportable_type": "Question",
  "reportable_id": 1,
  "reason": "spam",
  "comment": "Publicité déguisée"
}
```

**Validation Rules:**
- `reportable_type`: required, in:Question,Answer
- `reportable_id`: required, exists (in respective table)
- `reason`: required, in:spam,offensive,false_info,other
- `comment`: nullable, string, max:500
- Unique constraint: user cannot report same content twice

**Success Response (201 Created):**
```json
{
  "message": "Signalement enregistré. Merci de contribuer à la modération."
}
```

**Error Responses:**
- `401 Unauthorized` - User not authenticated
- `404 Not Found` - Reportable content does not exist
- `422 Validation Error` - Invalid data or duplicate report
- `422 Duplicate Report`:
  ```json
  {
    "error": {
      "code": "DUPLICATE_REPORT",
      "message": "Vous avez déjà signalé ce contenu",
      "timestamp": "2026-01-31T10:00:00Z"
    }
  }
  ```

### Backend Implementation Details

**ReportService Implementation:**

```php
<?php

namespace App\Services;

use App\Events\ReportCreated;
use App\Models\Answer;
use App\Models\Question;
use App\Models\Report;
use App\Models\User;
use Illuminate\Database\Eloquent\Model;
use Illuminate\Support\Facades\DB;

class ReportService
{
    /**
     * Create a new report
     */
    public function createReport(User $reporter, array $data): Report
    {
        // Get the reportable model
        $reportable = $this->getReportableModel($data['reportable_type'], $data['reportable_id']);

        // Check if already reported by this user
        $existingReport = Report::where('reporter_id', $reporter->id)
            ->where('reportable_type', $data['reportable_type'])
            ->where('reportable_id', $data['reportable_id'])
            ->first();

        if ($existingReport) {
            throw new \InvalidArgumentException('Vous avez déjà signalé ce contenu');
        }

        DB::beginTransaction();
        try {
            // Create report
            $report = Report::create([
                'reporter_id' => $reporter->id,
                'reportable_type' => $data['reportable_type'],
                'reportable_id' => $data['reportable_id'],
                'reason' => $data['reason'],
                'comment' => $data['comment'] ?? null,
                'status' => 'pending',
            ]);

            // Fire event for admin notification
            event(new ReportCreated($report));

            DB::commit();

            return $report;
        } catch (\Exception $e) {
            DB::rollBack();
            throw $e;
        }
    }

    /**
     * Get the reportable model instance
     */
    private function getReportableModel(string $type, int $id): Model
    {
        $model = match ($type) {
            'Question' => Question::class,
            'Answer' => Answer::class,
            default => throw new \InvalidArgumentException('Invalid reportable type'),
        };

        $instance = $model::find($id);

        if (!$instance) {
            throw new \InvalidArgumentException('Le contenu à signaler n\'existe pas');
        }

        if ($instance->is_deleted ?? false) {
            throw new \InvalidArgumentException('Ce contenu a déjà été supprimé');
        }

        return $instance;
    }

    /**
     * Get pending reports for admin
     */
    public function getPendingReports(int $page = 1): array
    {
        $reports = Report::where('status', 'pending')
            ->with(['reporter:id,name,email', 'reportable'])
            ->orderByDesc('created_at')
            ->paginate(20, ['*'], 'page', $page);

        return [
            'reports' => $reports->items(),
            'pagination' => [
                'current_page' => $reports->currentPage(),
                'last_page' => $reports->lastPage(),
                'total' => $reports->total(),
            ],
        ];
    }
}
```

```php
            ], 422);
        }
```

**Custom Validation Rule:**

```php
<?php

namespace App\Rules;

use App\Models\Answer;
use App\Models\Question;
use Illuminate\Contracts\Validation\Rule;

class ValidReportableType implements Rule
{
    public function __construct(private ?string $type) {}

    public function passes($attribute, $value): bool
    {
        $model = match ($this->type) {
            'Question' => Question::class,
            'Answer' => Answer::class,
            default => null,
        };

        if (!$model) {
            return false;
        }

        return $model::where('id', $value)
            ->where('is_deleted', false)
            ->exists();
    }

    public function message(): string
    {
        return 'Le contenu à signaler n\'existe pas';
    }
}
```

**BLoC Implementation:**

```dart
class ReportBloc extends Bloc<ReportEvent, ReportState> {
  final CreateReport _createReport;

  ReportBloc({required CreateReport createReport})
      : _createReport = createReport,
        super(ReportInitial()) {
    on<SubmitReport>(_onSubmitReport);
  }

  Future<void> _onSubmitReport(
    SubmitReport event,
    Emitter<ReportState> emit,
  ) async {
    emit(ReportSubmitting());

    final result = await _createReport(
      CreateReportParams(
        reportableType: event.reportableType,
        reportableId: event.reportableId,
        reason: event.reason.name,
        comment: event.comment,
      ),
    );

    result.fold(
      (failure) => emit(ReportError(failure.message)),
      (_) => emit(ReportSubmitted()),
    );
  }
}
```

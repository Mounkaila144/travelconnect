## Story

**En tant qu'** utilisateur,
**Je veux** pouvoir noter une réponse,
**Afin d'** indiquer sa qualité et aider au calcul du score de confiance.

---

## Acceptance Criteria

1. Chaque réponse affiche un système de notation (1-5 étoiles)
2. L'utilisateur peut noter en tapant sur les étoiles
3. La note est enregistrée immédiatement avec feedback visuel
4. L'utilisateur peut modifier sa note
5. L'auteur d'une réponse ne peut pas noter sa propre réponse
6. La note moyenne est recalculée après chaque vote
7. L'endpoint POST `/api/answers/{id}/rate` enregistre la note
8. L'endpoint retourne la nouvelle moyenne

### Rating Model Specification

[Source: architecture/4-modèles-de-données.md#4.4]

**Rating Model Attributes:**
- `id`: bigint - Unique identifier
- `answer_id`: bigint - Answer being rated (FK)
- `user_id`: bigint - User who rated (FK)
- `score`: tinyint - Rating value (1-5)
- `created_at`, `updated_at`: timestamp

**Relationships:**
- Belongs to Answer
- Belongs to User

**Constraint:** Unique composite key on (answer_id, user_id) - one rating per user per answer

**Database Schema:**
```typescript
interface Rating {
  id: number;
  answer_id: number;
  user_id: number;
  score: 1 | 2 | 3 | 4 | 5;
  created_at: string;
  updated_at: string;
}
```

### API Endpoint Specification

[Source: architecture/5-spécification-api-rest.md#5.3.5]

**Endpoint:** `POST /api/answers/{id}/rate`

**Authentication:** Required (Bearer token)

**Request Body:**
```json
{
  "score": 5
}
```

**Validation Rules:**
- `score`: required, integer, between:1,5
- User cannot rate their own answer

**Success Response (200 OK):**
```json
{
  "average_rating": 4.3,
  "ratings_count": 11
}
```

**Error Responses:**
- `401 Unauthorized` - User not authenticated
- `403 Forbidden` - User is answer author (cannot self-rate)
- `404 Not Found` - Answer does not exist
- `422 Validation Error` - Invalid score (not 1-5)

**Error Format (403 - Self Rating):**
```json
{
  "error": {
    "code": "CANNOT_RATE_OWN_ANSWER",
    "message": "Vous ne pouvez pas noter votre propre réponse",
    "timestamp": "2026-01-31T10:00:00Z"
  }
}
```

### Backend Implementation Details

**RatingService Implementation:**

```php
<?php

namespace App\Services;

use App\Events\AnswerRated;
use App\Models\Answer;
use App\Models\Rating;
use App\Models\User;
use Illuminate\Support\Facades\DB;

class RatingService
{
    /**
     * Rate an answer or update existing rating
     */
    public function rateAnswer(Answer $answer, User $user, int $score): array
    {
        // Prevent self-rating
        if ($answer->user_id === $user->id) {
            throw new \InvalidArgumentException('Vous ne pouvez pas noter votre propre réponse');
        }

        // Validate score
        if ($score < 1 || $score > 5) {
            throw new \InvalidArgumentException('La note doit être entre 1 et 5');
        }

        DB::beginTransaction();
        try {
            // Find or create rating
            $rating = Rating::updateOrCreate(
                [
                    'answer_id' => $answer->id,
                    'user_id' => $user->id,
                ],
                [
                    'score' => $score,
                ]
            );

            // Recalculate average rating
            $this->recalculateAverageRating($answer);

            // Reload answer to get updated values
            $answer->refresh();

            // Fire event for trust score update
            event(new AnswerRated($answer, $rating, $user));

            DB::commit();

            return [
                'average_rating' => $answer->average_rating,
                'ratings_count' => $answer->ratings_count,
            ];
        } catch (\Exception $e) {
            DB::rollBack();
            throw $e;
        }
    }

    /**
     * Recalculate average rating for an answer
     */
    private function recalculateAverageRating(Answer $answer): void
    {
        $stats = Rating::where('answer_id', $answer->id)
            ->selectRaw('AVG(score) as average, COUNT(*) as count')
            ->first();

        $answer->update([
            'average_rating' => $stats->count > 0 ? round($stats->average, 1) : null,
            'ratings_count' => $stats->count,
        ]);
    }

    /**
     * Get user's rating for an answer
     */
    public function getUserRating(int $answerId, int $userId): ?int
    {
        $rating = Rating::where('answer_id', $answerId)
            ->where('user_id', $userId)
            ->first();

        return $rating?->score;
    }
}
```

**Controller Implementation:**

```php
<?php

namespace App\Http\Controllers\Api;

use App\Http\Controllers\Controller;
use App\Http\Requests\RateAnswerRequest;
use App\Models\Answer;
use App\Services\RatingService;
use Illuminate\Http\JsonResponse;

class AnswerController extends Controller
{
    public function __construct(
        private readonly RatingService $ratingService
    ) {}

    /**
     * Rate an answer
     */
    public function rate(RateAnswerRequest $request, int $answerId): JsonResponse
    {
        $answer = Answer::findOrFail($answerId);

        try {
            $result = $this->ratingService->rateAnswer(
                answer: $answer,
                user: $request->user(),
                score: $request->validated()['score']
            );

            return response()->json($result);
        } catch (\InvalidArgumentException $e) {
            return response()->json([
                'error' => [
                    'code' => 'CANNOT_RATE_OWN_ANSWER',
                    'message' => $e->getMessage(),
                ]
            ], 403);
        }
    }
}
```

```dart
class RatingStarsInputWidget extends StatefulWidget {
  final int? initialRating;
  final Function(int) onRatingChanged;
  final bool isLoading;
  final double size;

  const RatingStarsInputWidget({
    this.initialRating,
    required this.onRatingChanged,
    this.isLoading = false,
    this.size = 32,
  });

  @override
  State<RatingStarsInputWidget> createState() => _RatingStarsInputWidgetState();

class _RatingStarsInputWidgetState extends State<RatingStarsInputWidget>
    with SingleTickerProviderStateMixin {
  int? _hoverRating;
  late AnimationController _animationController;

  @override
  void initState() {
    super.initState();
    _animationController = AnimationController(
      duration: const Duration(milliseconds: 200),
      vsync: this,
    );
  }

  @override
  void dispose() {
    _animationController.dispose();
    super.dispose();
  }

  void _onStarTap(int rating) {
    if (widget.isLoading) return;

    // Haptic feedback
    HapticFeedback.lightImpact();

    // Animate
    _animationController.forward().then((_) => _animationController.reverse());

    // Call callback
    widget.onRatingChanged(rating);
  }

  @override
  Widget build(BuildContext context) {
    return Row(
      mainAxisSize: MainAxisSize.min,
      children: List.generate(5, (index) {
        final starValue = index + 1;
        final isSelected = (widget.initialRating ?? 0) >= starValue;
        final isHovered = (_hoverRating ?? 0) >= starValue;

        return MouseRegion(
          onEnter: (_) => setState(() => _hoverRating = starValue),
          onExit: (_) => setState(() => _hoverRating = null),
          child: GestureDetector(
            onTap: () => _onStarTap(starValue),
            child: ScaleTransition(
              scale: Tween<double>(begin: 1.0, end: 1.2).animate(
                CurvedAnimation(
                  parent: _animationController,
                  curve: Curves.easeInOut,
                ),
              ),
              child: Icon(
                isSelected || isHovered ? Icons.star : Icons.star_border,
                color: isSelected
                    ? Colors.amber
                    : isHovered
                        ? Colors.amber.shade300
                        : Colors.grey,
                size: widget.size,
              ),
            ),
          ),
        );
      }),
    );
  }
}
```

**BLoC Handler:**

```dart
Future<void> _onRateAnswer(
  RateAnswer event,
  Emitter<QuestionDetailState> emit,
) async {
  if (state is! QuestionLoaded) return;

  final currentState = state as QuestionLoaded;

  emit(RatingAnswer(currentState.question, event.answerId));

  final result = await _rateAnswer(
    RateAnswerParams(
      answerId: event.answerId,
      score: event.score,
    ),
  );

  result.fold(
    (failure) {
      emit(RatingError(currentState.question, failure.message));
      // Revert to previous state after showing error
      Future.delayed(const Duration(seconds: 2), () {
        emit(QuestionLoaded(currentState.question));
      });
    },
    (ratingResult) {
      // Update answer in question's answer list
      final updatedQuestion = currentState.question.copyWith(
        answers: currentState.question.answers.map((answer) {
          if (answer.id == event.answerId) {
            return answer.copyWith(
              averageRating: ratingResult.averageRating,
              ratingsCount: ratingResult.ratingsCount,
              userRating: event.score,
            );
          }
          return answer;
        }).toList(),
      );

      emit(AnswerRated(
        updatedQuestion,
        event.answerId,
        ratingResult.averageRating,
        ratingResult.ratingsCount,
      ));

      // Show success message
      // (SnackBar will be shown in UI layer)
    },
  );
}
```

```dart
      // Success - show feedback
      ScaffoldMessenger.of(context).showSnackBar(
        const SnackBar(
          content: Text('Note enregistrée'),
          duration: Duration(seconds: 2),
        ),
      );
    } else if (state is RatingError) {
      // Error - revert optimistic update
      setState(() {
        _tempRating = null;
        _isSubmitting = false;
      });

      ScaffoldMessenger.of(context).showSnackBar(
        SnackBar(
          content: Text(state.message),
          backgroundColor: Colors.red,
        ),
      );
    }
  },
  child: // ... widget tree
)
```

```php
// In RatingService
public function rateAnswer(Answer $answer, User $user, int $score): array
{
    // Check if user is banned (middleware handles this but double-check)
    if ($user->is_banned) {
        throw new \InvalidArgumentException('Votre compte est suspendu');
    }

    // Prevent self-rating
    if ($answer->user_id === $user->id) {
        throw new \InvalidArgumentException('Vous ne pouvez pas noter votre propre réponse');
    }

    // Check if answer is deleted
    if ($answer->is_deleted) {
        throw new \InvalidArgumentException('Cette réponse n\'existe plus');
    }

    // Validate score range
    if ($score < 1 || $score > 5) {
        throw new \InvalidArgumentException('La note doit être entre 1 et 5');
    }

    // ... proceed with rating
}
```

```php
        // Update rating
        $response = $this->actingAs($user)->postJson("/api/answers/{$answer->id}/rate", ['score' => 5]);

        $response->assertStatus(200)
            ->assertJson([
                'average_rating' => 5.0,
                'ratings_count' => 1, // Still only 1 rating
```

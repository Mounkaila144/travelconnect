### App Store Review Guidelines Compliance

**Critical Guidelines to Follow:**

1. **2.1 App Completeness:**
   - App must be fully functional
   - No placeholder content
   - All features must work
   - No crashes or critical bugs

2. **2.3 Accurate Metadata:**
   - Screenshots must reflect actual app
   - Description must be accurate
   - No misleading claims

3. **4.2 Minimum Functionality:**
   - App must provide substantial features
   - Not just a website wrapper
   - Unique value proposition

4. **5.1.1 Data Collection and Storage:**
   - Privacy policy must be provided
   - Clear explanation of data usage
   - Proper permission requests
   - User consent for data collection

5. **5.1.2 Data Use and Sharing:**
   - Explain third-party data sharing
   - List all third-party SDKs
   - Obtain user consent

**Common Rejection Reasons to Avoid:**

1. Crashes or bugs during review
2. Incomplete or broken features
3. Missing privacy policy
4. Confusing user interface
5. Inappropriate content
6. Guideline violations

### Firebase Cloud Messaging Integration

[Source: architecture/7-apis-externes.md#7.3]

**API Details:**
- **Base URL:** https://fcm.googleapis.com/v1
- **Authentication:** Service Account JWT (Firebase Admin SDK)
- **Rate Limits:** No limit for individual messages
- **Documentation:** https://firebase.google.com/docs/cloud-messaging

**Endpoints Used:**
- `POST /projects/{project}/messages:send` - Send notification to device

**Integration Notes:**
- Use `kreait/firebase-php` package for Laravel backend
- Firebase project must be configured for both iOS (APNs) and Android
- Service account JSON must be kept secure and never committed to git
- FCM tokens can become invalid and should be refreshed

### API Endpoint Specification

[Source: architecture/5-spécification-api-rest.md#5.3.3]

**Endpoint:** `POST /api/user/fcm-token`

**Request Body:**
```json
{
  "fcm_token": "firebase_token_here"
}
```

**Validation Rules:**
- `fcm_token`: required, string, max:500

**Success Response (204 No Content):**
No body returned.

**Error Responses:**
- `401 Unauthorized` - User not authenticated
- `403 Forbidden` - User is banned
- `422 Validation Error` - Invalid fcm_token

**Error Format:**
```json
{
  "error": {
    "code": "VALIDATION_ERROR",
    "message": "Les données fournies sont invalides",
    "details": {
      "fcm_token": ["Le token FCM est requis"]
    },
    "timestamp": "2026-01-31T10:00:00Z"
  }
}
```

### Backend FCMService Implementation

[Source: architecture/11-architecture-backend-laravel.md#11.1]

**File Location:** `app/Services/FCMService.php`

**Key Implementation:**

```php
<?php

namespace App\Services;

use Kreait\Firebase\Factory;
use Kreait\Firebase\Messaging\CloudMessage;
use Kreait\Firebase\Messaging\Notification;
use Kreait\Firebase\Messaging\AndroidConfig;
use Kreait\Firebase\Messaging\ApnsConfig;
use Illuminate\Support\Facades\Log;

class FCMService
{
    private $messaging;

    public function __construct()
    {
        $factory = (new Factory)->withServiceAccount(config('firebase.credentials'));
        $this->messaging = $factory->createMessaging();
    }

    /**
     * Send push notification to device
     */
    public function sendNotification(
        string $fcmToken,
        array $notification,
        array $data = []
    ): bool {
        try {
            $message = CloudMessage::withTarget('token', $fcmToken)
                ->withNotification(Notification::create(
                    $notification['title'],
                    $notification['body']
                ))
                ->withData($data)
                ->withAndroidConfig(
                    AndroidConfig::fromArray([
                        'priority' => 'high',
                        'notification' => [
                            'channel_id' => 'travelconnect_notifications',
                            'sound' => 'default',
                        ],
                    ])
                )
                ->withApnsConfig(
                    ApnsConfig::fromArray([
                        'payload' => [
                            'aps' => [
                                'alert' => [
                                    'title' => $notification['title'],
                                    'body' => $notification['body'],
                                ],
                                'sound' => 'default',
                                'badge' => 1,
                                'content-available' => 1,
                            ],
                        ],
                    ])
                );

            $this->messaging->send($message);

            Log::info('FCM notification sent', [
                'token' => substr($fcmToken, 0, 10) . '...',
                'title' => $notification['title'],
            ]);

            return true;
        } catch (\Kreait\Firebase\Exception\Messaging\InvalidArgument $e) {
            Log::error('Invalid FCM token', [
                'token' => substr($fcmToken, 0, 10) . '...',
                'error' => $e->getMessage(),
            ]);
            return false;
        } catch (\Kreait\Firebase\Exception\Messaging\NotFound $e) {
            Log::error('FCM token not found', [
                'token' => substr($fcmToken, 0, 10) . '...',
                'error' => $e->getMessage(),
            ]);
            return false;
        } catch (\Exception $e) {
            Log::error('FCM notification failed', [
                'error' => $e->getMessage(),
            ]);
            return false;
        }
    }

    /**
     * Send notification to multiple devices
     */
    public function sendMulticast(
        array $fcmTokens,
        array $notification,
        array $data = []
    ): array {
        $results = [];

        foreach ($fcmTokens as $token) {
            $results[$token] = $this->sendNotification($token, $notification, $data);
        }

        return $results;
    }
}
```

```dart
import 'package:firebase_core/firebase_core.dart';
import 'package:firebase_messaging/firebase_messaging.dart';
import 'package:flutter_local_notifications/flutter_local_notifications.dart';

// Top-level function for background message handling
@pragma('vm:entry-point')
Future<void> firebaseMessagingBackgroundHandler(RemoteMessage message) async {
  await Firebase.initializeApp();
  print('Handling background message: ${message.messageId}');
  // Process notification in background
}

class NotificationService {
  final FirebaseMessaging _firebaseMessaging = FirebaseMessaging.instance;
  final FlutterLocalNotificationsPlugin _localNotifications =
      FlutterLocalNotificationsPlugin();
  final ApiClient _apiClient;

  NotificationService(this._apiClient);

  Future<void> initialize() async {
    // Configure local notifications
    const androidSettings = AndroidInitializationSettings('@mipmap/ic_launcher');
    const iosSettings = DarwinInitializationSettings(
      requestAlertPermission: false,
      requestBadgePermission: false,
      requestSoundPermission: false,
    );

    await _localNotifications.initialize(
      const InitializationSettings(
        android: androidSettings,
        iOS: iosSettings,
      ),
      onDidReceiveNotificationResponse: _onNotificationTapped,
    );

    // Create Android notification channel
    const androidChannel = AndroidNotificationChannel(
      'travelconnect_notifications',
      'TravelConnect Notifications',
      description: 'Notifications for questions and answers',
      importance: Importance.high,
    );

    await _localNotifications
        .resolvePlatformSpecificImplementation<
            AndroidFlutterLocalNotificationsPlugin>()
        ?.createNotificationChannel(androidChannel);

    // Configure background message handler
    FirebaseMessaging.onBackgroundMessage(firebaseMessagingBackgroundHandler);

    // Handle foreground messages
    FirebaseMessaging.onMessage.listen(_handleForegroundMessage);

    // Handle notification tap when app is in background
    FirebaseMessaging.onMessageOpenedApp.listen(_handleNotificationTap);

    // Handle notification tap when app was terminated
    final initialMessage = await _firebaseMessaging.getInitialMessage();
    if (initialMessage != null) {
      _handleNotificationTap(initialMessage);
    }
  }

  Future<bool> requestPermission() async {
    final settings = await _firebaseMessaging.requestPermission(
      alert: true,
      badge: true,
      sound: true,
      provisional: false,
    );

    return settings.authorizationStatus == AuthorizationStatus.authorized;
  }

  Future<String?> getFcmToken() async {
    try {
      final token = await _firebaseMessaging.getToken();
      return token;
    } catch (e) {
      print('Error getting FCM token: $e');
      return null;
    }
  }

  Future<void> registerTokenWithBackend(String token) async {
    try {
      await _apiClient.post('/user/fcm-token', data: {
        'fcm_token': token,
      });
    } catch (e) {
      print('Error registering FCM token: $e');
      rethrow;
    }
  }

  void _handleForegroundMessage(RemoteMessage message) {
    print('Foreground message received: ${message.notification?.title}');

    // Display local notification when app is in foreground
    _localNotifications.show(
      message.hashCode,
      message.notification?.title,
      message.notification?.body,
      const NotificationDetails(
        android: AndroidNotificationDetails(
          'travelconnect_notifications',
          'TravelConnect Notifications',
          importance: Importance.high,
          priority: Priority.high,
        ),
        iOS: DarwinNotificationDetails(),
      ),
      payload: message.data.toString(),
    );
  }

  void _handleNotificationTap(RemoteMessage message) {
    print('Notification tapped: ${message.data}');

    // Navigate based on notification data
    final data = message.data;
    if (data.containsKey('question_id')) {
      // Navigate to question detail
      // This will be implemented in notification navigation handler
    }
  }

  void _onNotificationTapped(NotificationResponse response) {
    print('Local notification tapped: ${response.payload}');
    // Handle local notification tap
  }
}
```

### Error Handling Strategy

[Source: architecture/18-stratégie-de-gestion-derreurs.md]

**Backend Error Scenarios:**
- Invalid FCM token format (return 422)
- Firebase service unavailable (log error, return 500)
- Token not found in Firebase (invalidate token in DB)
- Network timeout (retry with exponential backoff)

**Frontend Error Scenarios:**
- Permission denied (show explanation, offer to open settings)
- Firebase initialization failed (show error message, retry)
- Token registration failed (retry on next app launch)
- Network error during registration (queue for retry)

**User-Friendly Error Messages:**
- Permission denied: "Les notifications sont désactivées. Vous pouvez les activer dans les paramètres."
- Registration failed: "Impossible d'activer les notifications. Réessayez plus tard."
- Firebase error: "Erreur de configuration des notifications. Contactez le support."

### Security Considerations

[Source: architecture/15-sécurité-et-performance.md]

**Critical Security Rules:**
1. **NEVER** commit Firebase service account JSON to git
2. **NEVER** expose Firebase credentials in client-side code
3. **ALWAYS** validate FCM tokens server-side before storing
4. **ALWAYS** use authenticated endpoints for token registration
5. **STORE** service account JSON outside web root
6. **ROTATE** Firebase credentials if compromised
7. **VALIDATE** notification data to prevent injection attacks

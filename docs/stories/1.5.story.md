## Story

**En tant qu'** utilisateur connecté,
**Je veux** pouvoir me déconnecter de l'application,
**Afin de** sécuriser mon compte sur un appareil partagé.

## Acceptance Criteria

1. Un bouton "Déconnexion" est accessible dans les paramètres
2. Une confirmation est demandée avant déconnexion
3. Le token local est supprimé après déconnexion
4. Le token est invalidé côté serveur
5. L'utilisateur est redirigé vers l'écran de login
6. L'endpoint POST `/api/auth/logout` invalide le token courant

### Logout API Specification

[Source: architecture/5-spécification-api-rest.md#5.3.2]

**Endpoint:** `POST /api/auth/logout`

**Authentication:** Required (Bearer token in Authorization header)

**Request Body:** None

**Success Response:**
- Status: `204 No Content`
- Body: Empty

**Error Responses:**
- `401 Unauthorized` - No valid token provided
- `500 Server Error` - Internal server error

**Example Request:**
```bash
curl -X POST https://api.travelconnect.app/api/auth/logout \
  -H "Authorization: Bearer 1|sanctum_token_here"
```

### Backend Implementation

[Source: architecture/11-architecture-backend-laravel.md#11.4]

**File Location:** `app/Http/Controllers/Api/AuthController.php`

**Logout Method Implementation:**

```php
<?php

namespace App\Http\Controllers\Api;

use App\Http\Controllers\Controller;
use Illuminate\Http\Request;
use Illuminate\Http\Response;

class AuthController extends Controller
{
    public function logout(Request $request): Response
    {
        // Get the current user's access token
        $token = $request->user()->currentAccessToken();

        if ($token) {
            // Delete the current access token
            $token->delete();

            // Log the logout event (optional)
            \Log::info('User logged out', [
                'user_id' => $request->user()->id,
                'token_name' => $token->name,
            ]);
        }

        return response()->noContent();
    }

    /**
     * Optional: Logout from all devices
     */
    public function logoutAll(Request $request): Response
    {
        // Delete all user's tokens
        $request->user()->tokens()->delete();

        \Log::info('User logged out from all devices', [
            'user_id' => $request->user()->id,
        ]);

        return response()->noContent();
    }
}
```

### Laravel Sanctum Token Management

[Source: Laravel Sanctum Documentation]

**Token Deletion Methods:**

1. **Current Token Only:**
```php
$request->user()->currentAccessToken()->delete();
```

2. **All User Tokens:**
```php
$request->user()->tokens()->delete();
```

3. **Specific Token:**
```php
$request->user()->tokens()->where('name', 'mobile-app')->delete();
```

**Token Verification:**
- After logout, token is removed from `personal_access_tokens` table
- Subsequent requests with deleted token will return 401 Unauthorized
- Sanctum middleware automatically handles token validation

**AuthBloc Logout Event Handler:**

```dart
class AuthBloc extends Bloc<AuthEvent, AuthState> {
  final LogOut logOut;
  final AuthLocalDataSource localDataSource;

  AuthBloc({
    required this.logOut,
    required this.localDataSource,
  }) : super(AuthInitial()) {
    on<SignOutRequested>(_onSignOutRequested);
  }

  Future<void> _onSignOutRequested(
    SignOutRequested event,
    Emitter<AuthState> emit,
  ) async {
    emit(AuthLoading());

    // Call backend to invalidate token
    // Even if this fails, we still clear local token
    try {
      await logOut();
    } catch (e) {
      // Log error but continue with local logout
      print('Logout API call failed: $e');
    }

    // Delete token from secure storage
    await localDataSource.deleteToken();

    // Emit unauthenticated state
    emit(Unauthenticated());
  }
}
```

### Secure Token Storage

[Source: Story 1.2 Implementation]

**Token Storage Methods:**

```dart
class AuthLocalDataSource {
  final FlutterSecureStorage secureStorage;

  AuthLocalDataSource(this.secureStorage);

  static const _tokenKey = 'auth_token';

  Future<void> saveToken(String token) async {
    await secureStorage.write(key: _tokenKey, value: token);
  }

  Future<String?> getToken() async {
    return await secureStorage.read(key: _tokenKey);
  }

  Future<void> deleteToken() async {
    await secureStorage.delete(key: _tokenKey);
  }

  Future<bool> hasToken() async {
    final token = await getToken();
    return token != null && token.isNotEmpty;
  }
}
```

### State Cleanup on Logout

**Best Practices:**

1. **Clear Authentication State:**
   - AuthBloc emits Unauthenticated
   - User data cleared from memory

2. **Clear Profile State:**
   - ProfileBloc reset to initial state
   - Profile data cleared

3. **Clear Map/Questions State:**
   - Clear cached questions
   - Reset map position
   - Clear filters

4. **Clear Notifications State:**
   - Clear notification history
   - Unregister FCM token (optional)

5. **Clear Secure Storage:**
   - Delete auth token
   - Keep app preferences (theme, language, etc.)

**Implementation:**

```dart
Future<void> _onSignOutRequested(

  Emitter<AuthState> emit,
```

### Error Handling Strategy

**Logout Error Scenarios:**

1. **Network Error (API call fails):**
   - Still delete local token
   - Still redirect to login
   - Log error for monitoring
   - User can log back in

2. **Token Already Invalid:**
   - API returns 401
   - Treat as successful logout
   - Delete local token
   - Redirect to login

3. **Server Error (500):**
   - Still delete local token
   - Still redirect to login
   - Token will be invalid anyway after timeout
   - Show error message to user (optional)

**Implementation:**

```dart
Future<void> _onSignOutRequested(
  SignOutRequested event,
  Emitter<AuthState> emit,
) async {
  emit(AuthLoading());

  try {
    await logOut();
  } on NetworkException catch (e) {
    // Network error - continue with local logout
    print('Network error during logout: $e');
  } on UnauthorizedException catch (e) {
    // Token already invalid - continue with local logout
    print('Token already invalid: $e');
  } catch (e) {
    // Other errors - still continue with local logout
    print('Error during logout: $e');
  }

  // Always delete local token and logout
  await localDataSource.deleteToken();
  emit(Unauthenticated());
}
```

### Security Considerations

[Source: architecture/15-sécurité-et-performance.md]

**Logout Security:**

1. **Token Invalidation:**
   - ALWAYS invalidate token server-side
   - Deleting local token is not enough
   - Prevents token reuse if device is compromised

2. **Session Cleanup:**
   - Clear all user data from app state
   - Clear cached API responses
   - Clear any temporary files

3. **Logout from All Devices:**
   - Provide option to logout from all devices
   - Useful if device is lost or stolen
   - Invalidates all user's tokens

4. **Audit Logging:**
   - Log logout events with timestamp
   - Log user ID and token name
   - Helps with security monitoring

5. **Rate Limiting:**
   - Apply rate limit to logout endpoint (prevent abuse)
   - Allow reasonable number of logout attempts

**Best Practices:**

- Never expose token in error messages
- Always use HTTPS for logout endpoint
- Handle logout gracefully even if user is already logged out
- Clear sensitive data from memory after logout
- Don't cache user data after logout

### Performance Considerations

**Logout Performance:**

- Logout should be fast (< 500ms ideally)
- Network call to API is async (don't block UI)
- Local token deletion is synchronous and fast
- State cleanup should be efficient
- Navigation should be immediate

**Optimization Tips:**

1. Show loading indicator during logout
2. Delete local token first, then call API in background
3. Don't wait for API response if it's slow
4. Pre-clear UI state before navigation
5. Use debouncing to prevent multiple logout attempts

```php
<?php

namespace Tests\Feature\Auth;

use App\Models\User;
use Illuminate\Foundation\Testing\RefreshDatabase;
use Laravel\Sanctum\Sanctum;
use Tests\TestCase;

class LogoutTest extends TestCase
{
    use RefreshDatabase;

    public function test_authenticated_user_can_logout(): void
    {
        $user = User::factory()->create();
        $token = $user->createToken('mobile-app');

        $response = $this->withToken($token->plainTextToken)
            ->postJson('/api/auth/logout');

        $response->assertStatus(204);

        // Verify token was deleted
        $this->assertDatabaseMissing('personal_access_tokens', [
            'id' => $token->accessToken->id,
        ]);
    }

    public function test_token_invalidated_after_logout(): void
    {
        $user = User::factory()->create();
        $token = $user->createToken('mobile-app');

        // Logout
        $this->withToken($token->plainTextToken)
            ->postJson('/api/auth/logout')
            ->assertStatus(204);

        // Try to use the same token for another request
        $response = $this->withToken($token->plainTextToken)
            ->getJson('/api/user/profile');

        $response->assertStatus(401);
    }

    public function test_unauthenticated_user_cannot_logout(): void
    {
        $response = $this->postJson('/api/auth/logout');

        $response->assertStatus(401);
    }

    public function test_logout_all_deletes_all_tokens(): void
    {
        $user = User::factory()->create();

        // Create multiple tokens
        $token1 = $user->createToken('device-1');
        $token2 = $user->createToken('device-2');
        $token3 = $user->createToken('device-3');

        // Logout from all devices
        $this->withToken($token1->plainTextToken)
            ->postJson('/api/auth/logout-all')
            ->assertStatus(204);

        // Verify all tokens deleted
        $this->assertDatabaseMissing('personal_access_tokens', [
            'tokenable_id' => $user->id,
        ]);
    }
}
```
